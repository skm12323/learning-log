## 0. 这一讲在整门课里的位置

程序 = **数据** + **对数据的操作**。Python 世界的"数据"长什么样、怎么存、怎么取，就是本讲内容。四个主角：数字（int/float）、字符串 str、列表 list、元组 tuple。学完你能把一组物理测量值放进程序，完成存取、解析、格式化输出——后面所有课都建在这上面。

## 1. 变量

### 1.1 为什么需要变量

不用变量的程序长这样：`print(6.626e-34 * 5e14)`——数字没有含义，而且普朗克常数要用第二次就得重打一遍。变量 = **给数据起个人类可读的名字**，之后用名字引用：

```python
h = 6.626e-34      # h 是名字，6.626e-34 是对象
nu = 5e14
print(h * nu)      # 3.313e-19
```

### 1.2 赋值语句到底做了什么（执行顺序很重要）

`x = 3` 做两件事：①右边先造出对象 3；②把名字 x **贴**到它上面。所以：

```python
x = 3
x = x * 2   # ① 算出 x*2=6（新对象） ② 把 x 重新贴到 6 上，旧的 3 被丢弃
```

这解释了为什么 `x = x + 1` 在编程里天经地义、在数学里是废话——**等号不是"相等"，是"绑定"**。

### 1.3 动态类型：名字没有类型，对象才有

```python
x = 3           # 此刻 x 贴着 int
x = "hello"     # 合法：把 x 改贴到字符串上
type(x)         # <class 'str'>
```

好处是灵活。代价（重要的坑）：**名字拼错不会报错，而是悄悄创建一个新变量**：

```python
velocity = 30
veloctiy = velocity * 2   # 拼错 → 新变量 veloctiy 诞生，velocity 没变
                          # 程序不报错，但结果悄悄错了
```

### 1.4 命名规范

- 小写字母 + 数字 + 下划线，数字不能开头：`particle_mass` ✓，`2mass` ✗
- 大小写敏感：`Mass` 与 `mass` 是两个名字
- 原则：**有含义优先**。物理语境里 `m`、`p`、`E` 可以；`flag1`、`data2` 尽量避免
- 随时用 `type(x)` 查看对象类型

**什么时候用变量**：所有要用第二次、或需要表达含义的值。宁可多起名字。

## 2. 数字：int 与 float

### 2.1 int：无限大的整数

```python
2**200
# 1606938044258990275541962092341162602522202993782792835301376
```

别的语言的整数 64 位封顶，Python 的 int 想多大有多大。算阶乘、组合数、大数幂直接算——做题时的隐形福利。

### 2.2 七个运算符，重点区分三种除法

```python
7 + 2    # 9
7 * 2    # 14
7 / 2    # 3.5    真除法：结果永远是 float（8/2 得 4.0，不是 4）
7 // 2   # 3      地板除：向下取整
7 % 2    # 1      取余（模）
7 ** 2   # 49     幂
```

`//` 对负数有陷阱：

```python
-7 // 2   # -4，不是 -3！它向负无穷方向取整
-7 % 2    # 1
```

**什么时候用什么**：科学计算用 `/`；算下标、分组用 `//`；判断整除与周期性用 `%`（`n % 2 == 0` 判偶数）；幂用 `**`。

### 2.3 float：双精度实数与它的"诚信问题"

```python
h = 6.626e-34         # 科学计数法 = 6.626×10⁻³⁴
0.1 + 0.2             # 0.30000000000000004
0.1 + 0.2 == 0.3      # False ！
```

原因：float 用二进制存储，0.1 在二进制下是无穷循环小数，存的只是近似值。**float 判等永远写成容差式**：

```python
abs(0.1 + 0.2 - 0.3) < 1e-12   # True
```

这不是 Python 的 bug，所有语言的双精度都如此。你以后写 numpy 全是 float，这条规则天天用——物理上你也早已习惯：测量值没有精确相等，只有误差内一致。

相关工具：

```python
round(3.14159, 2)   # 3.14 —— 改变值本身（四舍五入到 2 位）
int(3.9)            # 3 —— 直接砍掉小数，不四舍五入（陷阱）
1 + 0.5             # 1.5 —— int 与 float 混算自动升级为 float
```

### 2.4 bool 与 None

```python
3 > 2                # True   比较运算产生 bool
(3 > 2) and (1 > 5)  # False
not (3 > 2)          # False
0 < 5 < 10           # True   链式比较，数学写法直接搬过来
```

`and`/`or` 是**短路**的：`A and B` 中 A 为 False 时 B 根本不求值（下讲条件判断会用到这个特性）。

`None` 表示"还没有值"。两个高频场景先记着：函数没有 `return` 时自动返回 None；`x = None` 常用作占位符。

## 3. 字符串 str

### 3.1 为什么字符串极其重要

程序的一切**输入输出**都是字符串：读文件得到字符串、网络传输的是字符串、print 出去的也是字符串。数字是计算的核心，字符串是**界面与通道**——解析数据、生成报告、拼路径全靠它。

### 3.2 创建：三种引号各有场景

```python
s1 = 'hello'
s2 = "it's fine"       # 双引号里可以直接放单引号，不用转义
s3 = """第一行
第二行"""               # 三引号：原样保留换行，用于多行文本
```

转义：`\n` 换行、`\t` 制表符、`\\` 反斜杠本身。`r''` 原始字符串让反斜杠失效——写 Windows 路径时救命：

```python
path = "C:\\new\\table"   # 普通字符串：双反斜杠，容易写错
path = r"C:\new\table"    # 原始字符串：所见即所得
```

### 3.3 索引与切片：序列通用语法（练到肌肉记忆）

```python
s = "superconductivity"
#    0123456789...
s[0]     # 's'   正向索引从 0 开始
s[-1]    # 'y'   负索引从末尾数，-1 是最后一个
s[5]     # 'c'
```

切片完整语法 `s[起:止:步长]`，三条规则：

1. **含头不含尾**：`s[0:5]` 取下标 0~4
2. 起止可省：`s[:5]` 从头开始、`s[5:]` 到末尾、`s[:]` 全部（这也是复制的写法）
3. 步长默认 1：`s[::2]` 隔一取一；负步长反向：`s[::-1]` 整串反转

```python
s[0:5]   # 'super'
s[5:]    # 'conductivity'
s[::2]   # 'sprodciiy'（取偶数下标）
s[::-1]  # 'ytivitcudnocrepus'
```

两个对比要点：**切片越界不报错**（`s[0:100]` 合法，取到头为止），但**单索引越界报错**（`s[100]` → IndexError）。

这套语法字符串、list、numpy 数组**完全通用**——今天练熟的每一秒都在为 numpy 投资。

### 3.4 不可变：所有"修改"都返回新串

```python
s = "super"
s.upper()      # 'SUPER' —— 一个新字符串
s              # 'super' —— 原串纹丝不动
t = s.upper()  # 想要"修改"效果，必须接住返回值
s[0] = 'S'     # ✕ TypeError —— 不能按下标改字符串
```

为什么这样设计：字符串在程序里被到处共享，若可变，一处修改会殃及所有引用处。不可变 = 安全。"调用方法返回新对象"是 Python 的普遍风格，先适应它。

### 3.5 f-string：唯一需要掌握的格式化

```python
E = 3.313e-19
print(f"光子能量为 {E} J")     # 自动转字符串插入
print(f"E = {E:.3e} J")        # E = 3.313e-19 J —— 3 位有效数字科学计数
print(f"E = {E:.4f} J")        # 0.0000 J —— 小数格式对大科学计数不合适，选对格式！
print(f"[{E:>15.3e}]")         # 总宽 15 右对齐 —— 打表格用
print(f"效率 {0.876:.1%}")     # 效率 87.6% —— 百分比格式
```

什么时候用：**只要往字符串里插值就写 f-string**。老式 `%` 和 `.format()` 见到能认即可。

### 3.6 常用方法速查（每个亲手跑一遍）

```python
s = "  Hydrogen, Helium, Lithium  "
s.strip()                 # 'Hydrogen, Helium, Lithium'  去两端空白——清洗输入第一步
s.strip().split(', ')     # ['Hydrogen', 'Helium', 'Lithium']  按分隔符切开 → list！
", ".join(['a', 'b'])     # 'a, b'   list 拼回字符串（split 的逆操作）
"hydrogen".upper()        # 'HYDROGEN'
"a/b/c.txt".find('.txt')  # 5   找子串位置，找不到返回 -1
"electron" in "electronics"  # True  判断包含（比 find 更常用于判断）
"banana".count('a')       # 3
"data.csv".endswith('.csv')  # True  筛选文件名常用
"v1.2".replace('.', '-')  # 'v1-2'
len("hello")              # 5   注意 len 是函数：len(s)，不是 s.len()
```

**split/join 是解析与生成文本的核心组合**：读进一行 CSV → `split` → 字段列表 → 逐个 `float()` 转数值；反向生成同理。

### 3.7 字符串与数字互转

```python
int("42")      # 42
float("3.14")  # 3.14
str(3.14)      # '3.14'
int("42abc")   # ✕ ValueError —— 转换失败会炸，脏数据的第一个报错点
```

**`input()` 永远返回字符串**：`n = input()` 后 `n*2` 是字符串翻倍（'33'），不是数字乘二。

## 4. 列表 list（本讲主角）

### 4.1 为什么需要 list

变量一次只能绑一个值，而物理数据天然成串：一组能级、一排粒子坐标、逐帧模拟结果。list = **有序、可变、什么都能装**的容器。

### 4.2 创建与取用（索引/切片规则与字符串完全一致）

```python
energies = [1.2, 3.4, 0.5, 2.2]
mixed = [1, "two", 3.0, [4, 5]]   # 可混装，甚至装 list
len(energies)    # 4
energies[0]      # 1.2
energies[-1]     # 2.2
energies[1:3]    # [3.4, 0.5]
```

### 4.3 可变：原地增删改（各自的适用场景）

```python
logs = []
logs.append("t=0 启动")    # 尾部添加 ★最常用：循环里逐步收集结果
logs.insert(0, "标题")     # 指定位置插入（头部插队，代价高，少用）
last = logs.pop()          # 删除并**返回**末元素——"栈"行为
logs.remove("t=0 启动")    # 按值删除第一个匹配；值不存在则 ValueError
del logs[0]                # 按位置删除
logs[0] = "新内容"          # 按位置直接改
```

`append` 是你以后最高频的操作："建空列表 + 循环里 append" 是收集计算结果的标准范式（下一讲循环见）。

### 4.4 排序：sort() 与 sorted() 的返回值差异（高频坑）

```python
a = [3, 1, 2]
sorted(a)              # [1, 2, 3] —— 返回新列表，a 原封不动
a                      # [3, 1, 2]
a.sort()               # 原地排序，返回 None
a                      # [1, 2, 3]
a.sort(reverse=True)   # [3, 2, 1] 降序
```

**选择原则**：要保留原始顺序（原始数据不能动）→ `sorted()`；只想要个有序结果 → `.sort()`。
致命写法 `a = a.sort()` → a 变 None。返回 None 是 Python 在告诉你："我改的是原地，没有新东西给你"。

### 4.5 聚合、查找、拼接、初始化惯用法

```python
nums = [2, 3, 5, 7, 11]
sum(nums)      # 28
max(nums)      # 11
min(nums)      # 2
5 in nums      # True  成员判断
nums.index(7)  # 3     查位置（不存在则 ValueError）
nums.count(5)  # 1
[0]*10         # [0]*10 → 十个 0 —— ★初始化定长数组的惯用法，模拟中天天用
[1,2] + [3,4]  # [1, 2, 3, 4] 拼接出新列表
```

### 4.6 嵌套：二维数据的雏形

```python
m = [[1, 2, 3],
     [4, 5, 6]]    # 2 行 3 列
m[1][0]            # 4 —— 先取第 1 行，再取该行第 0 列
len(m)             # 2（行数）
len(m[0])          # 3（列数）
```

下个月的 numpy 数组就是这个思想的工业化版本。

### 4.7 ★全讲最重要：赋值不复制（别名问题）

```python
a = [1, 2, 3]
b = a            # 不是复制！只是把第二个名字贴到同一个列表上
b.append(4)
a                # [1, 2, 3, 4] —— a 也"变"了
a is b           # True —— 同一个对象

b = a.copy()     # 这才是复制（等价写法 a[:]）
b.append(99)
a                # [1, 2, 3, 4] —— 不受影响
```

为什么这样设计：列表可能非常大，若每次赋值都复制，传个参数就要拷贝一百万个元素。**默认传引用 = 高效；要复制 = 必须显式写 `.copy()`**。numpy 对此只会更严格（切片常常也是"视图"）。这个实验请亲手敲到亲眼看见 a 变了为止——它会在某个深夜救你一命。

### 4.8 list 陷阱清单

1. `b = a` 不是复制（别名）
2. `x = x.sort()` 得到 None
3. `nums[10]` 越界 → IndexError（切片越界则不报错）
4. `remove` 只删第一个匹配项

## 5. 元组 tuple

### 5.1 为什么存在一个"不能改的 list"

三个理由：①**安全**——一组不该变的值（常数表、坐标系定义）用 tuple 装，误改立刻报错而不是悄悄出错；②**能当字典的键**（下一讲伏笔，list 不行）；③语义上表达"固定结构的一组值"：坐标 (x, y, z) 天生三元组。

```python
consts = (6.626e-34, 2.998e8, 1.602e-19)
consts[0]        # 读取、索引、切片都没问题（规则同 list）
consts[0] = 1    # ✕ TypeError —— 这正是它的价值
```

### 5.2 单元素逗号陷阱

```python
(5)     # 这只是数字 5（括号是数学括号）
(5,)    # 这才是单元素 tuple —— 逗号才是 tuple 的标志
```

### 5.3 解包：tuple 的灵魂用法

```python
px, py, pz = 3, 4, 5     # 右边实为 (3,4,5)，拆开分别绑定三个名字
px, pz = pz, px          # 交换两个变量，一行搞定
h, c, e = consts         # 把常数表拆开用
```

场景：函数一次返回多个值（`return energy, momentum`）、遍历坐标对。这一招是 Python 代码优雅的重要来源。

### 5.4 list 还是 tuple？选择原则

**默认 list**（要增删改、收集数据）；满足"一组值语义上是不可分割的整体且不会变"（坐标、常数表、版本号）用 **tuple**。拿不准就用 list，不会错。

## 6. 概念总结表

| 类型 | 可变？ | 有序？ | 典型用途 | 关键记号 |
|---|---|---|---|---|
| int / float | 不可变 | — | 数值计算 | `//` 地板除、`%` 取余、float 判等用容差 |
| str | ✕ | ✓ | 输入输出、文本解析 | 切片、f-string、split/join |
| list | ✓ | ✓ | 收集与处理数据序列 | append、sorted、警惕别名 |
| tuple | ✕ | ✓ | 固定一组值、解包 | `(5,)` 带逗号、`a, b = b, a` |
